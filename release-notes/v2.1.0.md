A small update to 2.0.1: a complete tray menu and faster levelling. Your data and settings are untouched.

## Fixed
- **Tray quick panel was out of date.** The small window that opens from the tray icon still listed only the original seven pages. It now shows all 12: Overview, Statistics, Applications, Sessions, Timeline, Focus, Limits, Productivity, Projects, Reports, Achievements and Settings. The panel is now generated from the same list as the sidebar, so pages added in future cannot be forgotten again.

## Changed
- **Levelling is 2.25x faster.** Each level now needs roughly 44% of the XP it needed before (Level 2 at 44 XP, Level 3 at 133, Level 5 at 444, Level 10 at 2,000). Achievement XP values and your earned XP are unchanged, so an existing install may jump up a few levels once after updating. XP is still finite: leaving the computer running earns nothing.

## Downloads
- `WatchTower-Setup-2.1.0.exe` - per-user installer (supports in-app update checks).
- `WatchTower-Portable-2.1.0-x64.exe` - single-file portable build.
- `SHA256SUMS.txt` - SHA-256 of both files; the in-app updater verifies the installer against it.

Both files are **unsigned**, so Windows SmartScreen may warn on first launch. The animated logo above is rendered from the app's real 3D scene (a looping recording, since GitHub pages cannot run WebGL).
